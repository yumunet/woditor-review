# 解析とデータ設計

## フェーズ1の調査

提供データは日本語・英語それぞれ `texts/` に348 TXT。対応形式はコモン225、DB66、マップイベント37の計328ファイル。Header、マップ本体、タイルセット等20ファイルは対象外。既存 `analyze()` の日本語抽出は23,719 Slot、未認識行0。

`woditor_parser.py` がTXT・CSVの解析、抽出・翻訳対象判定・位置情報・特殊文字列検査・安全な書き換えを担当する。`woditor_translation_tool.py` は新規翻訳のextract/applyとcontext/usageのCLI、`woditor_review_tool.py` はスキーマ内包のレビューJSON build/validate/apply CLI。`review_adapter.py` は日英の対応付けとアプリ用の項目・警告・周辺情報への変換を担当し、CLIからは参照しない。アプリはUTF-8以外を拒否し、BOM・改行・特殊記号を保持する。

### 実データで確認した引数

- 先頭の `[A]` がコード。次の角括弧は数値・文字列引数の個数、`<…>` は深さ、前の丸括弧は数値、最後の丸括弧は文字列。
- 250: S1 は代入文字列、S2/S3/S4 はタイプ・データ・項目の名前参照なので除外。
- 300: S1 はコモン名、S2以降は入力文字列。名前だけを除外。210/211の実例は番号参照で文字列なし。文字列入力があれば既存抽出に従う。
- 122: 第2数値引数の下位8bitが0の手動文字列を対象。実例の0、256、262656を含む。
- 150: 第1数値引数の `0x70` マスクが `0x20` の文字列ピクチャのみ対象。画像ファイル・図形の指定は対象外。
- 401: 同じ深さの開始コマンド102/112との関係を保持。111（数値条件）の分岐を文字列条件と呼ばない。
- 未知のコードは既存の日本語抽出を維持し「コマンド文字列」とする。意味を推測しない。

### 対応付けと安全性

日本語のSlotを基準に、メタデータのキー・コマンドマスク・文字列位置を照合する。英語側の日本語有無は使わない。原文の文字オフセットを英訳へ転用しない。表示用セクションは言語ごとに独立してコマンド数と順序を検証する。

実データは同一構造の完全な対訳ではない。予備調査では一致261、行数差45、構造差22だったが、現在は以下の構造対応付けで全328ファイルを読み込む。表示用コマンドも翻訳されており、CSVはwoditor_parser.pyで引用符付きの文字列セルを抽出する。先頭列は常に項目0。DATANAME_LOAD_TYPE=0だけ、行末の<<!--DATANAME--!>>と末尾カンマの間を独立したデータ名として扱う。その他のモードはデータ名を表示せず、参照先を追跡しない。ヘッダー・数値・マーカー・末尾カンマを保持し、空の原文は翻訳項目にしない。トークン差・保護セクション差は警告として保持し、元ファイルには書き込まない。

- `review_adapter.py` が設定キー（マップではページも含む）を照合する。選択肢数・引数数から無効化された設定を検出し、削除設定を除外して警告する。
- コマンドはコード・深さ・数値引数・文字列数からアンカーを作り、順序を保って照合。旧122の末尾ゼロ引数を認識するが、元データは変更しない。
- 変更区間は編集距離の前向き／後ろ向き計算で、すべての最小コスト経路が共通して示すペアだけを採用する。複数候補がある項目はエラーとして除外し、他の確実な項目は同じファイルから読み込む。単なる行数差はエラーにしない。
- 数値引数の差があっても、前後構造により同種・同じ深さ・同じ文字列位置に一意に対応するものは警告で読み込む。ピクチャや文字列操作のモードが異なるものは同一視しない。
- Slotの `line` は日本語の位置、`enLine` は英語の位置。出力・回答JSON・修正TXT再取り込みにも英語の位置を引き継ぎ、追加コメント・設定削除の後へ誤って書き込まない。旧バックアップは `enLine` がなければ従来の `line` を使う。
- 言語ごとの表示コマンド対応は独立に検証し、英語版の追加コマンドも文脈に保持する。ファイルIDの不一致、形式・表示セクションの破損は従来どおりエラー。

## モデル

- TranslationSlot: 元のSlot ID、原文、英訳、キー、行番号、コマンドコード・種類・引数位置、構造識別子。
- ReviewItem: 1つ以上のSlot ID、機械的タイトル、承認、コメントスレッド、変更履歴。
- Context: 言語別の表示コマンド・行対応とセルフ変数直接参照。レビュー件数には含めない。
- File: 正規化した相対パス、UTF-8原文と英訳、BOM、SHA-256バージョン、解析結果と警告。

連続103コマンドは同一イベント・ページ・深さかつ実際に隣接している場合に1レビュー項目。Slotは個別に保持する。IDは初回の原文構造から作成し、再読込では同一原文・キー・構造を再検証して既存IDを引き継ぐ。曖昧な再対応は適用しない。

JSONは `schemaVersion: 1`。依頼にはpath、fileVersion、itemId、slotIds、commentId、原文と英訳、全投稿、周辺情報を含む。回答は同じID・バージョンを必須とし、判断・理由・必要ならSlot別変更を持つ。AI判断とユーザー承認は別。変更は対応AIコメントと結び、解決で確定、再開で旧訳に戻す。通常のファイル再読み込みは確認後に英訳を正式値として上書きし、標準では承認状態を維持する。外部上書きは確定済みreload履歴として保存し、それ以前の同じSlotのAI変更はコメントの状態を切り替えても再適用しない。バックアップはファイル・状態・履歴をすべて含む。

UIは単一カラムのTypeScript、解析はローカル配信PyodideをWeb Workerで実行。ZIPはfflate、保存はIndexedDB、PWAはローカルリソースだけをキャッシュする。通常のレビューは端末内で完結する。任意のGoogle Drive同期に接続した場合は、アプリ専用領域へレビュー全体を送受信する。同期の設計は [development.md](development.md#drive同期の実装)、設定手順は [google-drive.md](google-drive.md) を参照。
