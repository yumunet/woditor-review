# Woditor Review

WOLF RPGエディターの日本語原文と英訳TXTを比較し、コメントを付けて翻訳を確認するアプリです。データは使用中のブラウザに保存されます。ChatGPTへの受け渡しはファイルで行います。

このアプリはOpenAIのCodexを使用して開発されています。

## 起動

Node.js 24.15以降の24系、または26系以降を用意し、このディレクトリで実行します。

```powershell
npm ci
npm run dev
```

表示されたURLをブラウザで開いてください。アプリの使用にPythonのインストールは不要です。

インストール・オフライン利用には、本番ビルドを使用します。

```powershell
npm run build
npm run preview
```

`http://127.0.0.1:4173/` を開き、読み込みが完了してから利用してください。別の端末で使う場合はHTTPSで公開する必要があります。

## GitHub Pagesで公開

リポジトリの `Settings → Pages → Source` を **GitHub Actions** にします。`main` へpushすると、追加した公開用ワークフローが `https://ユーザー名.github.io/woditor-review/` へデプロイします。

クライアントIDを公開版へ組み込む場合は、`Settings → Secrets and variables → Actions` に `GOOGLE_CLIENT_ID` を登録してください。値はGitで追跡せず、ビルド時だけ設定ファイルへ書き込みます。公開後のJavaScriptにはIDが含まれます。未登録でも公開でき、アプリの接続設定から入力できます。

Google側の「承認済みのJavaScript生成元」には `https://ユーザー名.github.io` を登録します。末尾の `/woditor-review/` は付けません。

## ファイルを読み込む

メニューの「ファイルを読み込む」で、日本語と英語それぞれのUTF-8 TXTをまとめたZIPを指定します。対応するファイルの相対パスを揃えてください。

```text
japanese.zip: ja-JP/texts/BasicData/CommonEvent/042.txt
english.zip:  en-US/texts/BasicData/CommonEvent/042.txt
```

「読み込み結果」からエラー・警告を確認できます。各行を選ぶと日本語・英語の本文を閲覧できます。原文が空の項目は、周辺コマンドを確認して「原文を補う」から入力できます。

フォルダからファイルを開き、翻訳項目を確認します。項目名を選ぶと一覧・検索、下部の「コメント」から指摘を追加できます。確認が済んだ項目は「承認」してください。

## ChatGPTとの受け渡し

1. メニュー「AIレビューを依頼」で、最初に英訳を確認してもらう場合は「英訳をチェックして指摘・修正案を作る」、投稿済みコメントに対応してもらう場合は「既存コメントに回答・修正する」を選びます。
2. 対象ファイルを選び、「JSONを出力」と「英訳TXTを出力」を実行します。
3. 「指示文をコピー」でコピーした文、依頼JSON、英訳ZIP、[Python補助ツールと必要ファイル](docs/development.md#補助ツールの受け渡し)をChatGPTへ渡します。コピー後の「指示文を確認」で全文を閲覧できます。
4. ChatGPTが返したJSONを、メニュー「AIレビュー結果を読み込む」で指定します。修正済み英訳ZIPがある場合は一緒に指定します。
5. AIの指摘理由はコメント、修正案は英訳の差分として表示されます。確認して対応コメントを「解決」すると修正案が確定します。追加の修正依頼は指摘に返信し、「既存コメントに回答・修正する」で依頼します。再審で不採用になった案は「不採用の変更を破棄」してから解決してください。
6. 「英訳TXTを出力」で確定した英訳をZIPに保存します。未確定の変更案は含まれません。

出力対象は、PCではShift＋クリック、スマホでは長押ししてからドラッグすると範囲選択できます。選択済みの行から長押しすると範囲を解除します。ドラッグ中は一覧の上下端で自動スクロールします。

依頼・回答JSONと依頼用の英訳ZIPは、ファイル名末尾の12文字のIDで組み合わせを確認できます。英訳ZIPは依頼内容によらず `en-US_<ID>.zip` です。再審するときはコメントを再開して返信し、新しい依頼を出してください。

再読み込みも「ファイルを読み込む」を使用します。日本語原文ZIPを省略すると、現在の原文で英訳ZIPを読み込みます。既存ファイルは確認後に上書きし、項目ごとの再承認は不要です。コメント・解決状態・承認状態を保持し、必要なら確認画面で「変更された項目を未確認に戻す」を選べます。変更箇所と競合する保留案は、表示された件数を確認して破棄します。

## 保存・バックアップ

操作内容は自動保存されます。メニュー「状態をバックアップ」で日時付きのJSONを保存し、「バックアップを復元」から戻せます。復元は現在の作業を置き換えます。

端末・ブラウザ・開くURLを変える場合はバックアップで移行してください。ブラウザのデータ削除に備え、定期的なバックアップをおすすめします。

## Google Driveで同期

メニュー「Google Drive同期」からGoogleに接続し、「今すぐ同期」で原文・英訳・コメント・承認状態を別の端末と同期できます。初回は[Google OAuthの設定](docs/google-drive.md)が必要です。すべての端末で同じクライアントID・Googleアカウントを使用してください。

両方の端末で変更した場合は、どちらの状態を使うか選択します。Driveの状態を反映する前の端末データは、同期画面からバックアップ保存できます。必要なら「自動同期」を有効にしてください。自動同期はアプリを開いて接続している間だけ動作します。

Google接続は再読み込みや認証期限切れの後にやり直してください。接続を解除してもローカルの作業は続けられます。

開発・配信・検証・画面仕様は [docs/development.md](docs/development.md) にまとめています。

Pythonでの新規翻訳や未使用選択肢の検査・削除は [Pythonツール](docs/python-tools.md) を参照してください。
